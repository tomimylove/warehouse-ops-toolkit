# Announcements

Простой модуль — можно смело брать без предварительного изучения остальной
кодовой базы.

## Что делает

CRUD объявлений: заголовок, текст, автор, дата. Список — самые новые
сверху.

## Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/announcements` | Список всех объявлений |
| GET | `/announcements/:id` | Одно объявление |
| POST | `/announcements` | Создать (`{ title, body }`) |
| DELETE | `/announcements/:id` | Удалить |

## Модель данных

См. `prisma/schema.prisma`, модель `Announcement`.

## Что дальше по этому модулю

- Права доступа (кто может создавать/удалять) — пока не реализованы, ждут
  core-слоя ролей.
- Привязка автора к реальному пользователю — пока `authorId` произвольная
  строка, без FK на модель пользователя (её ещё нет).
