# UI components (design system)

Базовые компоненты из `specs/DESIGN_SYSTEM.md`. Модули приложения
используют только их для типовых элементов интерфейса (кнопки, поля,
карточки, статус-пилюли) — не пишут свою разметку/стили для того же самого.

Каждый компонент — простой `.tsx` + свой `.css`, без CSS-in-JS
зависимостей. Стили читают только токены из `../../styles/tokens.css`,
литералов цвета/отступов внутри компонентов быть не должно.
